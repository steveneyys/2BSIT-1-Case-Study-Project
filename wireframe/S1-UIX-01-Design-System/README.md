# S1-UIX-01 — Design System

## Overview
This design system provides the visual guidelines for the HOPE ERP website. It is aligned with the updated landing page to keep the interface consistent.

## Design Foundations
- **Primary color:** Electric blue — #074CE0
- **Background:** Near-white — #FCFCFD
- **Card surface:** White — #FFFFFF
- **Primary text / dark sections:** #16191F
- **Borders:** #DDE0E6
- **Headings:** Host Grotesk
- **Body text and controls:** Instrument Sans
- **Spacing:** 8, 16, 24, 32, 48, and 64px
- **Card corner radius:** 12px

## Included UI Examples
- Primary, secondary, destructive, and disabled buttons
- Text fields with normal, focus, error, and read-only states
- Checkboxes and navigation items
- Business record and account status labels
- Table, section header, and dialog examples
- Control-state examples

## Latest Updates
- Matched typography samples to the updated landing page.
- Added reusable landing-page text styles.
- Updated color labels and removed outdated visual guidelines.
- Aligned the Cancel and Delete buttons in the dialog example.
- Documented responsive layout, keyboard focus, and reduced-motion guidance.

## Validation
The updated design-system board was visually checked for text clipping, overflow, and button alignment.

Control states are visual references. They do not represent implemented website behavior.
