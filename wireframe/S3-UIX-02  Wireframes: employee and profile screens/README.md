# S3-UIX-02 — Wireframes: Employees and Profiles

**Purpose:** Ipakita ang employee list, add/edit forms, profile, at history access states.

**Screens:** Admin list, granted-HR User list, Add/Edit Employee, profile with history access, and restricted-history state.

**Important behavior:** Employee No. is unique and read-only after creation. Separation Date is optional but cannot be before Hire Date. Employment separation is different from a soft-deleted record. Job history and salary require the appropriate history-view permission.

**Guide reference:** Hope ERP Student Guide, §§1.2, 2.3, 3.5.
