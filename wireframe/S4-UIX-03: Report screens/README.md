# S4-UIX-03 — Report Screens and Audit Viewer Design

## Task
Design the report screens, including filters and print/export actions, and the audit viewer.

## Reports

- Active Employees
- All Employees
- Employee Job History

## Required Design Details

- Include Print and Save as PDF actions.
- Show the audit viewer as a separate design for the Superadmin.
