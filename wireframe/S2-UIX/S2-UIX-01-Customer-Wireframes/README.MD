# S2-UIX-01 — Wireframes: Customer Screens

## Overview
This folder contains the customer wireframes for  the HOPE, Inc. ERP system. They show the page structure and user flow before visual styling.

## Screens
- Customer list
- Customer details
- Add customer
- Edit customer
- Customer status and available actions

## Design notes
The wireframes follow the HOPE ERP workflow and use the existing role permissions. Actions and fields should match the customer-management requirements in the student guide.
