# S3-UIX-03 — Job History Timeline and Forms

## Purpose

This task documents the wireframes for viewing and managing employee job history.

## Screens to include

- Employee job history timeline or chronological list
- Add Job History form
- Edit Job History form
- Current and past assignment states
- Empty history state
- Validation error and save feedback states
- Restricted access state for users without history permission

## Design and behavior requirements

- Show job history in chronological order with clear effective dates or date ranges.
- Distinguish current assignments from past assignments without relying on color alone.
- Explain when the Separation Date may be left blank.
- Show validation for invalid date ranges, duplicate employee and effective date entries, and invalid salary values when applicable.
- Explain how the system determines the current assignment.
- If saving fails, preserve the entered values and show a clear error message.
- Use fictional sample data in the designs.

## Privacy and permissions

Protect salary and job history information. Show it only to users with the required permission. Apply this rule to profiles, timelines, summaries, reports, and exports.
