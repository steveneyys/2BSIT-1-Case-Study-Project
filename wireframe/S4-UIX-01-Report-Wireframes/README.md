# S4-UIX-01 — Report Wireframes

## Purpose
This folder contains the wireframes for the system's report screens.

## Screens Included
- Product Master List
- Active Employees
- All Employees
- Employee Job History
- Top Customers
- Top Products
- Top Sales

## Design Notes
- Reports are available according to the user's assigned access rights.
- Report results are read-only.
- Users can print or save report pages as PDF.
